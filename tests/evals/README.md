# Avaliações

Itens públicos do [bncc-benchmark](https://github.com/bncc-dev/bncc-benchmark) (CC BY 4.0) entram como regressão de **recusa de código inexistente**. A citação do benchmark fica aqui, não na interface.

Regras:

- nenhum código gerado pode deixar de existir no recorte;
- texto oficial não é editado;
- entradas sintéticas só cobrem formato inválido e lacunas oficiais.
